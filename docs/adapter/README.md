# Adapter Layer — функциональное описание

## Назначение

Adapter Layer — единственная точка контакта бота с внешним сервисом,
в котором общается пользователь. Он принимает сообщения из сервиса,
передаёт их в Bot Core и доставляет ответы обратно пользователю.

## Ответственность

- Устанавливает и поддерживает соединение с внешним сервисом.
- Получает новые сообщения по мере их появления.
- Приводит входящее событие к единому виду «сообщение от пользователя».
- Уведомляет Bot Core о каждом новом сообщении.
- По запросу Bot Core отправляет ответ в нужный чат.
- При необходимости показывает пользователю, что бот «печатает».

## Что НЕ делает

- Не вызывает языковую модель.
- Не решает, отвечать пользователю или нет.
- Не формирует текст ответа.
- Не хранит состояние диалога между сообщениями.
- Не знает, какой именно сервис используется за пределами модуля.

## Вход и выход (по смыслу)

| Направление | Что приходит / уходит |
|---|---|
| Из внешнего сервиса | Событие: новое сообщение от пользователя |
| В Bot Core | Сообщение в едином виде: текст, отправитель, чат |
| Из Bot Core | Готовый текст ответа и адресат |
| Во внешний сервис | Отправленное пользователю сообщение |

## Сценарии

1. **Новое сообщение.** Внешний сервис присылает событие → Adapter Layer
   приводит его к единому виду → передаёт в Bot Core.
2. **Ответ пользователю.** Bot Core возвращает текст и адресата →
   Adapter Layer отправляет сообщение в нужный чат.
3. **Индикация набора.** Пока модель формирует ответ, Adapter Layer
   (если сервис поддерживает) показывает пользователю «бот печатает».
4. **Сбой отправки.** Если отправить сообщение не удалось — факт
   фиксируется в логах, процесс не прерывается.
5. **Временная недоступность сервиса.** Adapter Layer продолжает
   попытки установить соединение, не завершая работу бота.

## Границы v1

- Реализуется один конкретный внешний сервис (Telegram).
- Обрабатываются только текстовые сообщения; нетекстовые игнорируются.
- Соединение инициирует бот, публичных входящих точек нет.

## Расширения

Пока нет. Файлы расширений размещаются в `docs/{module}/extensions/`
(см. `docs/README.md` §7). Примеры будущих расширений:

- поддержка второго внешнего сервиса (`adapter-whatsapp.md`),
- обработка вложений и медиа (`adapter-media.md`),
- групповые чаты и упоминания (`adapter-groups.md`).
